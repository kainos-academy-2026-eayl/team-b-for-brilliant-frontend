Nunjucks: data, blocks and output.

Use this beside the code. It describes the current Express/Nunjucks setup, not a browser-side framework.

Pass values by name

res.render('products/show.njk', { product });
// Equivalent data argument:
// { product: product }

product is now a context name the template can use: {{ product.name }}. If the key becomes item, the template must read {{ item.name }}. Ordinary controller variables are not automatically exposed.

Shared request values can be set through res.locals. In app.ts, these are isSignedIn, csrfToken and currentPath. They are available for that request, not shared between visitors. Express reference.

The configured views root is views/. Render 'products/index.njk', not a browser URL such as '/products'. Nunjucks runs on the frontend server and produces HTML. Template engines.

Use one shared document layout

{% extends "main.njk" %}

{% block title %}My page | B-Brilliant{% endblock %}

{% block content %}
  <h1>My page</h1>
  <p>{{ product.name }}</p>
{% endblock %}

This is a page-template pattern, not a standalone HTML document. Put extends first; do not duplicate the parent's html, body, header or menu. main.njk must not extend itself.

Blocks defined by the real main.njk
BlockUse
titleText inside the document's <title> element.
headPage-specific head content such as stylesheets or a style element.
contentThe main page markup.
scriptsPage-specific browser-script elements, in addition to shared scripts outside this block.

A child overrides the named block; if it does not override a block, the parent's default remains. extends is not the same as include: an include renders and inserts a piece at its position, while inheritance uses the parent's named slots.

{% include "products/products.css" %} in a <style> element inserts CSS text using the template loader. It is not a browser fetch of that path. A <link href="/static/styles.css">, on the other hand, tells the browser to fetch a stylesheet.

Source formatting versus page appearance

  • Indent nested markup and template instructions to make structure readable.
  • Close HTML elements and Nunjucks control tags independently: </ul> does not replace {% endfor %}.
  • Use CSS margins, padding, gap, grid or flex for visual spacing and layout, not extra indentation in a template.
  • Keep HTML semantics: headings for headings, buttons for actions and links for navigation.
  • With this app's autoescape: true, normal value output is escaped. Do not use | safe on untrusted data as a formatting shortcut.

Templates generate the content/structure; CSS presents that structure. The browser receives HTML, not an instruction to run Nunjucks. CSS reference · Nunjucks configuration.

When something looks wrong

SymptomStart here
A name is blankCompare the context key, property spelling and loop variable. Simple missing values usually output nothing under the default configuration.
Template not foundCheck the render, extends or include filename relative to the configured views root.
Page content disappearsCheck that the child overrides an actual parent block, such as content, with the same spelling.
Correct content, wrong spacingInspect the applied CSS and selectors, not only template indentation.
A script does not runCheck the scripts block and the actual served URL. A file under views/ is not automatically a public asset.
Backend changed but page did notServer-side template output is not a live connection. A new render or browser-side update is needed.

Missing values are not guaranteed to be harmless: calling a method on an undefined value can still fail. Check the observed error rather than assuming every mistake will produce a blank.

# Mission: Understand my frontend's backend communication

## Why
AI wrote much of this application, and I want to understand the code personally.
I want to follow what happens when I use my own product pages rather than depend
on AI's explanations without being able to check them.

## Success looks like
- Trace a product-page request from browser to frontend server to backend and back.
- Explain which parts exchange JSON and which part returns HTML.
- Describe the purpose of clients, controllers, middleware, models, schemas,
  services, types and utils using an example from this repository.
- Identify where to start looking when the backend returns unexpected data.

## Constraints
- Start with no assumed knowledge of HTTP requests, JSON or server-side rendering.
- Use the actual Node.js, Express and Nunjucks code in this repository.
- Keep lessons short, with one practical win and feedback on recall.

## Out of scope
- For the first lesson: rewriting the architecture, database internals,
  deployment and advanced authentication details.
